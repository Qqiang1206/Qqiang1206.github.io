The attitude — 态度

人物可以很疯，
服务必须很稳。

我们不把一次体验包装成权威测评，也不把协助包装成结果保证。真实体验，清楚边界。

  • Real play / 真实体验，不端着

    从真实用户视角去玩，讲好用的，也讲不好用的。体验记录是主观体验，不是专业测试报告。

  • Help / 能帮就帮，不能就说

    发布、部署、服务器等服务，按产品情况和实际成本确认。不做模糊承诺。

  • Ship / 先把产品送出去

    不追求一开始就做成巨型平台，先让产品流动起来，被看见、被使用、被讨论。

Service boundary — 服务边界

平台审核由平台方决定，玩码场不承诺一定审核通过。

证书、签名密钥和 API Key 不应由平台长期持有，归属需提前确认。

服务器费用和资源规格、流量与超额费用、备份与故障恢复责任，部署前逐项确认。

不默认承诺 7×24 小时运维。后续维护范围单独约定。

04 / FAQ & boundaries — 丑话与好处

丑话说在前面，
好处也摆在明面。

服务有边界，体验是主观的——这些先讲清楚，合作才愉快。

Q1

收费吗？

产品提交、展示和基础曝光按玩码场运营规则开放，不收费。上架协助、部署、服务器资源属于专项技术服务，按产品情况和实际成本单独评估确认。

Q2

体验记录是专业测试报告吗？

不是。Qqiang 实测是主观真实体验：从真实用户视角去玩，讲好用的，也讲不好用的，但不等同于专业测试报告。

Q3

能保证上架或审核通过吗？

不能。平台审核由平台方决定。我们能做的是把材料、流程和细节准备好，让你少走弯路。

Q4

服务器是永久的吗？

不是。资源规格、费用归属、备份方式和退出机制，都会在部署前逐项确认清楚。

Q5

提交了就一定被体验吗？

不一定。会按排队情况和兴趣安排，可能需要补充材料，但每一个提交都会被认真对待。
